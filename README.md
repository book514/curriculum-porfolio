# Parent-Facing K to 8 Curriculum Site: Portfolio Sample

**Live site:** https://arsheen.sayeed.github.io/curriculum-portfolio/

A curriculum website I designed and wrote so that families can see exactly what their
child is learning, when it happens, and which program it comes from, for every subject
from Pre-K through Grade 8.

This is an anonymized version of a site built for a working K to 8 school. The school
name, staff, contact details and school-specific documents have been removed.
"Sample Academy" is a fictional name.

## What the site does

- **Grade by grade navigation.** Families pick their child's grade and see only that
  grade's guides and books, rather than everything at once.
- **More than 40 family guides, readable on the page.** Each guide walks through the
  year unit by unit: what the child is learning, key vocabulary, and one concrete thing
  families can do at home. Every guide can also be printed.
- **The books we teach from.** Each grade lists its program, edition and publisher for
  every subject, in plain language.
- **Why we chose it.** Each core program has a short explanation of what it is, why it
  was selected, and where it falls short.
- **Year-end goals.** Each guide closes with what a child should be able to do by June
  and the habits at home that matter most.

## The curriculum work behind it

Every guide was written from curriculum maps that align each published program to the
Virginia Standards of Learning. Where a program did not cover a standard, the gap was
identified and filled with school-written units, lessons and packets, and the guides
say so openly.

Programs covered include:

- **Amplify** Core Knowledge Language Arts (CKLA), Kindergarten to Grade 4
- **Savvas** enVision Mathematics, myView Literacy, myPerspectives, Experience Science
  and myWorld Interactive, Kindergarten to Grade 8
- **Five Ponds Press** Science and Social Studies, Kindergarten to Grade 4
- **Learning Without Tears** Get Set for School, Pre-K

## Built with

One self-contained HTML file: HTML, CSS and plain JavaScript, with no frameworks and
no outside dependencies. It loads fast and can be hosted anywhere.
